# ADR-001: 混合检索——BM25 + 向量 + RRF 融合

- 状态: 已接受
- 日期: 2026-08-21（自根目录 `RAG_检索优化指南.md` 迁移）
- 相关: FEAT-013（语义搜索）

## 背景

单一向量检索（ChromaDB 余弦相似度）无法捕获词法匹配，专业术语、缩写、精确匹配场景召回率低。

## 决策

采用**向量检索 + BM25 词法检索 + RRF（Reciprocal Rank Fusion）融合**：

```
向量检索（语义匹配） + BM25（词法匹配） → RRF 融合 → 综合排序
```

- RRF 公式：`RRF_score(d) = Σ 1/(k + rank_i(d))`，`k=60`
- 向量与 BM25 各自召回 top 50，融合后进入重排序

## 后果

- 正面: 召回率 +15~30%；专业术语/缩写查询显著改善；对模糊 query 容错性更好
- 负面: 检索延迟增加（约 +50ms，可接受）；需要维护 BM25 索引
- 取舍: 未选用线性加权融合——权重难调，RRF 无需调参、鲁棒性更好

## 落地

- `backend/app/services/bm25.py` — BM25Service（rank-bm25）
- `backend/app/services/fusion.py` — `reciprocal_rank_fusion()`
- `backend/app/services/retriever.py` — 检索入口，`use_hybrid=True` 时启用
- 依赖: `rank-bm25`
