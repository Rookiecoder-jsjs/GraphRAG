# ADR-002: Query 预处理与重写

- 状态: 已接受
- 日期: 2026-08-21（自根目录 `RAG_检索优化指南.md` 迁移）
- 相关: FEAT-013（语义搜索）

## 背景

用户 query 通常简短、模糊、有歧义，直接检索效果差。

## 决策

通过 LLM 预处理 query 再检索：
- **重写（rewrite）**：扩展缩写与术语、显式化隐式概念、保持原意图
- **实体提取（extract_entities）**：从 query 提取实体名，用于图谱过滤/加权
- **扩展（expand_query）**：补充语义相关词
- **变体生成（generate_query_variants）**：生成语义等价的多个变体，供多查询检索使用

## 后果

- 正面: 模糊 query 准确率 +20%；缩写/专业术语识别率提升
- 负面: 每次检索增加一次 LLM 调用（延迟 +200ms 左右）
- 取舍: 已对预处理 LLM 调用关闭混合思考（`thinking_mode`），以控制延迟与成本

## 落地

- `backend/app/services/query_processor.py` — QueryProcessor（rewrite/extract/expand/variants）
- `backend/app/services/retriever.py` — `enable_rewrite=True` 时启用重写
