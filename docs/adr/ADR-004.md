# ADR-004: Cross-Encoder 重排序

- 状态: 已接受
- 日期: 2026-08-21（自根目录 `RAG_检索优化指南.md` 迁移）
- 相关: FEAT-013（语义搜索）

## 背景

混合检索召回大量候选 chunk 后，需要精排保证送入 LLM 的上下文相关性。

## 决策

采用 **Silicon Flow 的 Qwen3-Reranker-8B**（Cross-Encoder）对召回结果重排序：从召回候选中精选 top_k 送入 LLM 上下文。

## 后果

- 正面: 准确率 +20~40%；上下文聚焦度提升
- 负面: 每次检索增加一次 rerank API 调用（延迟 +100ms 左右）
- 取舍: 优先使用云端 API 而非本地模型——避免本地部署维护成本；未实现本地 Cross-Encoder 备选

## 落地

- `backend/app/services/reranker.py` — `rerank()`
- 召回量配置: 向量 + BM25 各召回 50，重排序精选 5
