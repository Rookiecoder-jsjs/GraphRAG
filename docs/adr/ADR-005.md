# ADR-005: 多查询检索（Multi-Query Retrieval）

- 状态: 已接受
- 日期: 2026-08-21（自根目录 `RAG_检索优化指南.md` 迁移）
- 相关: FEAT-013（语义搜索）

## 背景

单个 query 的表述方式有限，可能错过相关文档。

## 决策

采用多查询检索：**原始 query + LLM 生成的 N 个语义等价变体 → 分别检索 → 去重 → RRF 融合**。

- 变体数量由配置 `MULTI_QUERY_NUM_VARIANTS` 控制
- 变体生成: `QueryProcessor.generate_query_variants()`（语义等价、含同义词、不同表述）

## 后果

- 正面: 召回率 +20~40%；复杂/模糊 query 覆盖更广；降低对单个 query 表述的依赖
- 负面: 检索次数 ×(1+N)，延迟 +300ms 左右；需对结果去重
- 取舍: 变体数量设上限（默认 3），平衡覆盖与成本

## 落地

- `backend/app/services/retriever.py:242` — 调用 `generate_query_variants(query, settings.MULTI_QUERY_NUM_VARIANTS)`
- `backend/app/services/query_processor.py` — `generate_query_variants()`
