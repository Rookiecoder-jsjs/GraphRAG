# FEAT-023: 对话导出 Markdown

- 状态: 已完成（页面行为在代码中存在）
- 页面: `/chat`（ChatPage.vue 头部「导出」按钮）
- API: 无新端点（纯前端拼装，`utils/chatExport.js`）
- 数据表: 无新表（复用前端 messages/conversations 状态）

> ⚠️ **模型例外条目**：纯前端导出，豁免「1 功能 = 1 页面 + 1 API + 1 表」约束（先例 FEAT-020）。

## 功能说明

对话页头部「导出」按钮把当前会话（含加载的历史轮次与正在进行的回答）下载为 `{标题}-YYYYMMDD-HHmm.md`：标题取会话列表中的会话名，缺失时回退首条用户消息截 30 字 → 「未命名会话」；逐轮输出 `## 用户` / `## 助手`，流式回答带来源时附「参考来源」列表；无可导出内容时按钮禁用。文件名经安全化（剥非法字符/控制符/双向文本标记、去尾部点空格、限 60 字符），Blob + `a[download]` 下载，UTF-8 无 BOM。

## 边界

- 用原始 `content`（非 formattedHtml），不携带渲染产物
- 历史会话 sources 未持久化（FEAT-020 已知事实）→ 历史轮次自然无来源段，不伪造
- 新建会话可能尚未刷进 conversations 列表（仅挂载/激活/开下拉时刷新）→ 标题回退链覆盖，不加 watcher
