# website/ — NEXUS 官网

单文件静态官网（`index.html`），瑞士极简网格风，与 `frontend/src/styles/variables.css` 同一 token 体系（亮/暗双主题，localStorage key `theme` 与前端共用约定）。

- **查看**：双击 `index.html` 即可（零依赖、零网络请求、系统字体）
- **部署**：任意静态托管（GitHub Pages / Nginx / OSS），把本目录整个拷上去即可
- **内容口径**：全部取自根 `README.md` 实测信息（功能清单、管线阶段、测试数），无运营数据
