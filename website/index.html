核心功能SEC.01

10 FEATURES · 页面与 API 均已落地
F/01

文档知识库

上传 PDF / Word / TXT / MD，自动转 Markdown 并按标题层级切块，切块带前后邻居与父文档指针。

F/02

混合检索

多查询变体 + 向量召回 + BM25 关键词 + 图谱通道，RRF 融合后经 Qwen3-Reranker 精排，父文档扩展再重排。

F/03

知识图谱可视化

d3 力导向图谱，支持节点拖拽、实体编辑、合并与删除；实体按类型着色，可按名称模糊检索。

F/04

RAG 对话

流式输出、深度思考（推理过程独立帧展示）、意图路由（闲聊/拒答绕过检索）、对比模式、引用溯源。

F/05

仪表盘与时间线

文档 / 实体 / 标签统计、月度增长曲线、近期活动流、实体首现时间线与动画回放。

F/06

文档聚类地图

2D PCA 投影呈现全部文档的语义分布，相近主题自然聚簇，用于发现知识盲区。

F/07

MCP Server

标准 MCP (stdio) 暴露四个只读工具，Claude Code / Claude Desktop / codex 零前端投入直接查询知识库。

F/08

RAG 测评框架

检索指标（Hit@K / MRR / nDCG）+ LLM-as-judge 生成指标，13 个 gold 用例作为提示词改动的回归门禁。

F/09

用户隔离

JWT 账号认证 + bcrypt 哈希；Neo4j / ChromaDB / BM25 全部按 user_id 过滤，删除操作强制带隔离条件。

F/10

工程健壮性

请求级 X-Request-ID 追踪、API 限流、上下文注入预算熔断、检索缓存自愈、启动对账、全量备份脚本。

检索管线SEC.02

RETRIEVE() · 9 STAGES · TTL+LRU CACHED

一次提问，
经过九个阶段。

查询先做意图分类：闲聊与拒答直接短路，事实类问题才进入检索管线。九个阶段全部有界——每一路召回有候选上限，注入提示词前有token 预算熔断，超限按块裁剪，不炸窗口。

services/retriever.py
GRAPH_RRF_WEIGHT 可配 · 多查询变体 ×3
P/01
意图路由

LLM 判定 fact_retrieval / chitchat / should_reject，分类失败自动回退 RAG。

P/02
查询改写 + 多查询变体

会话改写消除指代，并行生成查询变体扩大召回覆盖面。

P/03
向量 + BM25 双路召回

逐查询并行执行，Embedding 逐文本缓存，BM25 索引启动预热。

P/04
图谱通道

实体邻域展开作为独立召回列表，权重可配（auto / on / off）。

P/05
RRF 融合

多列表倒数排名融合，图谱通道权重独立可调。

P/06
Qwen3-Reranker 精排

融合候选重排序，截断保留头部 seed chunks。

P/07
父文档扩展

补充前后邻居 chunk 与同节兄弟块，恢复被切块打断的上下文。

P/08
扩展集再重排

扩展内容按相关性归位排序，邻居块不被驱逐。

P/09
上下文预算熔断

<context> 区硬 token 上限，超限按块裁剪后注入 LLM，流式返回带引用的回答。

快速开始SEC.04

3 STEPS · PYTHON 3.11+ / NODE 18+ / DOCKER
S/01

启动基础设施

Docker Compose 拉起 Neo4j 与 ChromaDB。

# Neo4j :7687 · Chroma :8000
docker-compose up -d
S/02

配置环境变量

从模板复制，填入 API Key 与 JWT 密钥。

cp .env.example .env
# 必填：Embedding/Rerank/LLM Key
# JWT_SECRET 用 secrets 生成
S/03

安装并启动

后端 8001，前端 5173，一键脚本可用。

pip install -r requirements.txt
npm run dev   # 前后端同起
